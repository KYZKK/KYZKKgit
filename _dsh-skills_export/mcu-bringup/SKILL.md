# 新板点亮

## 顺序不能颠倒

供电 → 复位 → 时钟 → 调试口 → GPIO → 串口 → 其他外设。跳过任何一步，都会在后面付出十倍时间。

## 1. 上电检查（不写代码）

- 量每路电源的实际电压与上电时序，对一遍手册的上电顺序要求。
- 量复位脚电平，确认没有被外部拉住。
- 确认 BOOT 引脚状态对应期望的启动源。
- 确认晶振起振：示波器看波形和幅度，不要只看代码里"配置成功了"。

## 2. 复位源

读对应芯片的复位标志寄存器（如 `RCC->CSR`），把上次复位原因打出来：上电、看门狗、软件、欠压、引脚复位。**反复复位但代码看着正常时，先看这里。**

## 3. 时钟树

- 先跑内部 RC 确认能动，再切外部晶振。
- 逐项确认：PLL 输入频率、倍频系数、各级分频、总线最高频率、Flash 等待周期。
- 超频或等待周期不足的表现是"偶尔跑飞"，不是"跑不起来"。
- 外设时钟要单独使能，很多"寄存器写不进去"就是时钟没开。

## 4. 调试口

连不上时按顺序查：供电 → 地 → SWDIO/SWCLK 接线 → 是否需要 connect under reset → 调试口是否被固件关掉或复用成 GPIO → 低功耗模式是否关掉了调试模块。

## 5. GPIO

- 先做最简单的：推挽输出点灯，确认能翻转。
- 再确认复用功能编号（AF number）与手册一致——移植时最常见的错。
- 上拉/下拉、开漏、驱动能力按外部电路选，不要照抄例程。
- 输入脚注意浮空；未使用的脚建议配成模拟或输出，别悬空。

## 6. 串口

第一个能用的外设应该是 UART，它是后面所有调试的输出通道。

- 先确认波特率误差在 2% 以内（按实际时钟分频算）。
- 先做阻塞发送，能打印了再上中断和 DMA。
- 打印乱码按此顺序查：波特率 → 时钟源 → 引脚复用 → TX/RX 是否接反。

## 7. SPI / I2C / DMA

- SPI：先确认 CPOL/CPHA 与从机一致，再用逻辑分析仪看波形。
- I2C：先确认上拉电阻与总线电平，再确认从机地址是 7 位还是 8 位写法。
- DMA：先确认通道映射、触发源、传输宽度、地址自增方向，再确认完成标志与中断。
- M7/M33 记得处理 Cache 一致性，否则数据"偶尔对偶尔错"。

## 记录

每通过一步就记一条：做了什么、读了哪个寄存器、期望值、实际值。下次换板子，这份记录就是 checklist。
